## 📚 Topics & Tags

This repository covers major areas of DSA, including:

| Category | Topics |
|----------|--------|
| **Arrays & Strings** | Two Pointers, Sliding Window, Prefix Sum, Kadane's Algorithm |
| **Linked Lists** | Fast/Slow Pointers, Reversal, Cycle Detection, Merge |
| **Stacks & Queues** | Monotonic Stack, Next Greater Element, Valid Parentheses |
| **Hashing** | Hash Maps, Sets, Frequency Counting, Subarray Sums |
| **Recursion & Backtracking** | Subsets, Permutations, N-Queens, Sudoku Solver |
| **Binary Trees & BST** | Traversals (DFS/BFS), LCA, Diameter, Serialization |
| **Graphs (BFS/DFS)** | Topological Sort, Shortest Path, Connected Components, MST |
| **Dynamic Programming (DP)** | 0/1 Knapsack, LIS, Edit Distance, House Robber, Matrix Chain |
| **Greedy Algorithms** | Interval Scheduling, Huffman Coding, Activity Selection |
| **Two Pointers & Sliding Window** | Subarray Problems, Palindromes, Container With Most Water |
| **Math & Bit Manipulation** | XOR Properties, Bit Counting, Power of Two, Fast Exponentiation |
| **Sorting & Searching** | Binary Search Variants, Quick/Merge Sort, Kth Element |
| **STL-Based Solutions** | Priority Queue, Ordered Map/Set, Algorithms, Iterators |
